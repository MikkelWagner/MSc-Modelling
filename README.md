# MSc Modelling

Modelling repository for MSc thesis.

## Structure

- `HyDesign/` – HyDesign source code and thesis-specific modifications
- `scripts/` – Python scripts for model runs and analysis
- `data/` – Model input data
- `config/` – Model configuration files
- `notebooks/` – Jupyter notebooks and exploratory analysis
- `results/` – Generated model results

## HyDesign baseline

This project is based on HyDesign developed by DTU Wind and Energy Systems.

Original repository:
